配置流程

按照下列纵向步骤完成从订阅到连接。强调顺序操作，避免跳过订阅导入或节点更新。

第一步：选择套餐并开通

对比基础版、旗舰版与团队版的流量、设备数与线路类型。个人日常与流媒体优先旗舰版；多人共用选择团队版。完成支付后账号立即生效。

第二步：复制机场订阅链接

进入用户中心获取通用订阅地址。该链接可用于 Clash 系、V2Ray 系客户端。请勿公开分享订阅，以免流量被盗用。

第三步：下载对应客户端

Windows 与 macOS 可使用 Clash 内核图形客户端或 v2rayN；iOS 常用 Shadowrocket 或同类应用；Android 使用 Clash Meta 系列。请从各软件官方来源获取安装包，本站仅提供导入说明。

第四步：导入订阅并更新节点

在客户端粘贴订阅 URL，执行一次更新以拉取节点列表。开启定时更新可减少过期配置。按地区或专线标签筛选节点。

第五步：测速连接与分流

选择延迟较低的节点连接。需要解锁流媒体时使用标记原生的节点；游戏走 IPLC。若失败，切换协议或提交工单，旗舰与团队用户享有优先处理。

常见问题

白嫖(Galaxy)是什么？如何从官网开始使用？

白嫖(Galaxy)是提供机场订阅的网络加速与梯子服务品牌。您可在本官网查看套餐、按配置流程获取订阅并下载常用客户端完成连接。名称强调高性价比接入，服务本身为付费订阅制。

配置流程必须按顺序吗？漏掉哪一步最容易失败？

建议严格按选择套餐、复制订阅、安装客户端、导入更新、选择节点这五步进行。最常见失败原因是未更新订阅或使用了非官方修改版客户端，导致节点列表为空或无法握手。

客户端应在哪里下载？本站是否提供安装包？

本站作为白嫖(Galaxy)官网提供订阅与说明，不托管第三方安装包。请到 Clash、Shadowrocket、v2rayN 等项目或应用商店的官方渠道下载，再回来粘贴机场订阅链接。

三个套餐如何选择？流量用尽怎么办？

轻度浏览选基础版；流媒体加游戏选旗舰版；多人共用或定制路由选团队版。流量按套餐周期统计，用尽后连接会受限，可升级套餐或等待下一周期重置，具体以控制台显示为准。

设备数超限或需要企业分流怎么处理？

同时在线设备超过套餐上限时，新设备无法连接。团队版支持更多终端与定制路由，可由客户经理协助配置分流规则。个人用户可先下线闲置设备再接入。

节点连不上或流媒体仍锁区如何排查？

先更新订阅并更换同区域其他节点，关闭系统代理冲突后再试。流媒体请使用旗舰版原生解锁节点，并避免浏览器额外地区插件。持续失败可提交工单并注明客户端名称与错误提示。
